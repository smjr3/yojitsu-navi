# ダミーデータのシナリオ

`npx tsx scripts/generate-dummy.ts [--seed 42] [--asOf 2026-10-27] [--out data]` で生成する架空の会社のデータ。
同じ seed・asOf なら毎回バイト単位で同じ出力になる（乱数は mulberry32、`_meta.json` の日時も asOf から導出）。
デモと結合テストはこのデータを前提にしている。会社名・人名はすべて架空。

規模（seed=42, asOf=2026-10-27）: メンバー 30 人（履歴 31 行、うち工数だけの幽霊 1 人）／契約 21 件／作業実績 17,860 行（2025-04〜2026-10 の 19 か月）。

## 紐付け（`data/mapping.csv`）と表記ゆれ

- ルールは契約ごとに 1 行。更新契約（C001/C002、C003/C004 など）は**同じ顧客・案件名で別契約 ID の行**があり、作業日の月で選ばれる。
- **みなと銀行は案件名が空**（顧客の全工数）。工数側の案件名は「勘定系周辺システム保守」「勘定系周辺 障害対応」「月次報告」「（空）」とばらついている。
- 工数側の顧客名・案件名は意図的に揺らしてある。正規化（NFKC・空白圧縮・小文字化・法人格の前後除去）で一致すること:

| ルール側 | 工数側に現れる表記 |
|---|---|
| 青葉物流 | 株式会社青葉物流 / 青葉物流株式会社 / 青葉物流 |
| さくら製菓 / ECサイト保守 | さくら製菓株式会社, （株）さくら製菓, ㈱さくら製菓, `さくら製菓 `（末尾空白） / ＥＣサイト保守（全角）, ecサイト保守, `ECサイト保守 ` |
| ひまわり食品 | 株式会社ひまわり食品 / ひまわり食品（株） |
| 北斗建設 | `北斗建設 株式会社` / `北斗建設  株式会社`（空白 2 つ） / 北斗建設 |

- **ルールの無い工数**（`NO_RULE` で未紐付け）: 「社内 / 勉強会」（全員が時々 1h）、「もみじ不動産 / 営業支援ツール検討」（M018、2026-08〜10）。
- **顧客名が空**の行（`EXCLUDED_NO_CUSTOMER`）: 5% の日に「社内会議」0.5〜1h。

## 作業実績（`data/worklogs/YYYY-MM.csv`）

- 2025-04-01 〜 asOf（既定 2026-10-27）の**平日のみ**。土日と `holidays.csv` の日は無い。
- 1 人 1 日 6〜8h を 1〜3 件に 0.25h 刻みで分ける。課長は 2〜4h。4% の日は丸一日休み。
- 契約の選び方は所属チームの契約を月額に比例した重みで。**約 10% は他チームの契約への応援**（`memberTeamId` ≠ 契約のチーム）。
- 0.25 / 0.5 のような小さい時間が混ざる（C013、C009、分割の端数）。
- **hours = 0 の行**: `2026-05-12, M014, 株式会社ひまわり食品`（無視される。`WORKLOG_INVALID_HOURS`）。
- 作業内容は 定例 / 問い合わせ対応 / 障害対応 / 調査 / リリース作業 / 監視・運用 / パッチ適用 / ドキュメント更新 / 改修 / テスト。幽霊メンバーは「データ移行」、C010 準備は「導入準備」。
- 行は 日付 → メンバー → 顧客 → 案件 → 時間 → 作業内容 の順に並ぶ（生成と取得スクリプトで共通の並び）。
- `_meta.json`: `{ fetchedAt: "<asOf>T09:00:00+09:00", adapter: "dummy", seed, asOf }`。

## 祝日（`data/holidays.csv`）

2025-01-01〜2027-12-31 の国民の祝日を計算で求めたもの（振替休日、2026-09-22 の国民の休日を含む）
＋ 会社休日（12/29〜1/3、8/13〜8/15）。BOM 付き UTF-8 で保存してあり、BOM の扱いも試せる。

## アサイン（`data/assignments.csv`）

FY2026 の契約に対する配分（`assignment` 方式の着地見込み用）。各メンバーの月合計は 1.0 以下。
C010（将来開始）には 2027-01〜03 の配分があり、C012（実績ゼロ）にも M024 が 0.1 で入っている。

## 検証結果の期待値（`npm run validate`）

エラー 0 件。警告は次のとおり:

- `WORKLOG_INVALID_HOURS` 1 件（hours=0 の行）
- `UNMAPPED_WORKLOG` 3 グループ（社内/勉強会、もみじ不動産/営業支援ツール検討、やまびこ通信/ネットワーク監視 = OUT_OF_PERIOD）
- `EXCLUDED_NO_CUSTOMER`（顧客名なし 約 330 時間）
- `UNKNOWN_MEMBER` M099
- `RATE_MISSING` M025 × 19 か月

## 別シナリオを作る

- `--seed` を変えると工数の乱数だけ変わる（マスタ・契約は固定）。
- `--asOf` を早めると作業実績の期間が短くなる（例 `--asOf 2025-12-15` で FY2025 途中の状態）。
- マスタや契約を変えたいときは `scripts/generate-dummy.ts` の `TEAMS` / `MEMBERS` / `RATES` / `CONTRACTS` / `MAPPINGS` を編集する。
